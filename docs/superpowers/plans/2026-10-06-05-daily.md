# 5단계: 일일 콘텐츠 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 일일 루프를 넣는다. 지하주차장, 지하주차장 일일 퀘스트(상품권 수급), 단계 미션, 특수 임무, 출석, 랭킹 2종(층, 주차장 깊이)과 닉네임, 화면 잠금. 이직 해금은 100층.

**Architecture:** 규칙은 전부 `shared/`. 지하주차장 한 판(30초)은 `runParking(power)`가 닫힌 공식으로 결과를 내고, 입장 의도(`enterParking`)를 적용할 때 바로 정산한다. 같은 함수라 클라이언트가 결과 팝업을 예측해 바로 보여줄 수 있다. 입장권 충전(15분마다 1장, 최대 16장)은 `settle`에서 시간으로 정산한다. 날짜 경계(KST 0시)와 요일(토요일 2배)은 `shared/time.ts`가 서버 시간(`state.lastTick`)으로 판단한다. 일일 기록은 날짜가 바뀌면 읽을 때 새로 시작한다(지연 초기화). 랭킹은 서버가 `sync` 직후 기록이 오르면 공유 컬렉션에 쓰고, `ranking`/`setNickname` 원격 함수로 읽고 쓴다.

**Tech Stack:** 1~4단계와 같음

### Task 2: KST 날짜와 요일

**Files:** Create `shared/time.ts`, `shared/time.test.ts`

**Interfaces:** `KST_OFFSET_MS = 9 * 3600_000`, `kstDay(ms: number): string` ("YYYY-MM-DD"), `kstWeekday(ms: number): number` (0 = 일요일 … 6 = 토요일), `isSaturday(ms: number): boolean`

테스트:
```ts
import { describe, expect, test } from "vitest";
import { isSaturday, kstDay, kstWeekday } from "./time";

describe("KST days", () => {
  test("a KST day starts at 00:00 KST (15:00 UTC the day before)", () => {
    expect(kstDay(Date.UTC(2026, 9, 6, 14, 59))).toBe("2026-10-06");
    expect(kstDay(Date.UTC(2026, 9, 6, 15, 0))).toBe("2026-10-07");
  });

  test("weekdays in KST", () => {
    // 2026-10-10 is a Saturday.
    expect(kstWeekday(Date.UTC(2026, 9, 10, 3, 0))).toBe(6);
    expect(isSaturday(Date.UTC(2026, 9, 9, 15, 0))).toBe(true);
    expect(isSaturday(Date.UTC(2026, 9, 10, 15, 0))).toBe(false);
  });
});
```
구현:
```ts
// Days and weekdays in Korean time (UTC+9), from the server's clock: daily resets at 00:00 KST.
export const KST_OFFSET_MS = 9 * 3600_000;

export function kstDay(ms: number): string {
  return new Date(ms + KST_OFFSET_MS).toISOString().slice(0, 10);
}

export function kstWeekday(ms: number): number {
  return new Date(ms + KST_OFFSET_MS).getUTCDay();
}

export function isSaturday(ms: number): boolean {
  return kstWeekday(ms) === 6;
}
```

### Task 4: 지하주차장

**Files:** Create `shared/data/parking.ts`, `shared/parking.test.ts`. Modify `shared/settle.ts`, `shared/actions.ts`.

**Interfaces:**
- `PARK_PASS_MAX = 16`, `PARK_RECHARGE_SEC = 900`, `PARK_RUN_SEC = 30`, `PARK_STEP_SEC = 0.2`, `PARK_CHEST_EVERY = 20`, `PARK_HP_BASE = 100`, `PARK_HP_GROWTH = 1.1`
- `parkHp(meter: number): Big` = `PARK_HP_BASE × PARK_HP_GROWTH^(meter−1)`
- `chestTickets(k: number): number` = `floor(1.25^(k−1))` (k번째 상자, 20k m)
- `interface ParkingRun { depth: number; chests: number; tickets: number }`
- `runParking(power: Power): ParkingRun` — 30초 동안 1m씩: `시간 = 1 / (dps / (parkHp(m) × hpMult) + drainPerSec) + PARK_STEP_SEC`. 30초를 넘기는 m은 도달하지 못한 것. 깊이 = 처치한 m 수. 상자 = `floor(depth / 20)`, 응시권 = 상자들의 합.
- `rechargePasses(parking, dt)` — `settle`에서 부른다. 가득이면 이월 0.
- `Intent`: `{ k: "enterParking" }`. 입장권이 없으면 `no_pass`. 적용: 입장권 −1, `runParking(heroPower(s))`, 응시권 지급, `parking.best` 갱신, 일일 기록(`dailyOf(s)` → 날짜가 다르면 새로 시작) `entries += 1`, `bestDepth = max`.
- `dailyOf(s: GameState): GameState["daily"]` — `kstDay(s.lastTick)`과 다르면 `{ day: 오늘, entries: 0, bestDepth: 0, claimed: [] }`.

테스트(핵심):
```ts
test("30 seconds: depth, a chest every 20 m, exponentially more tickets", () => {
  expect(chestTickets(1)).toBe(1);
  expect(chestTickets(10)).toBe(Math.floor(1.25 ** 9));
  const weak = runParking(P(Big.of(100)));
  expect(weak.depth).toBeGreaterThan(0);
  const strong = runParking(P(Big.of(1, 6)));
  expect(strong.depth).toBeGreaterThan(weak.depth);
  expect(strong.chests).toBe(Math.floor(strong.depth / 20));
});
test("passes recharge one per 15 minutes up to 16", () => { … settle 로 확인 … });
test("entering spends a pass, pays tickets, records the day", () => { … });
test("no pass, no entry", () => { … "no_pass" … });
test("the client's preview equals what the server applies", () => {
  const s = …; const preview = runParking(heroPower(s));
  const after = applyIntent(s, { k: "enterParking" });
  expect(after.tickets - s.tickets).toBe(preview.tickets);
});
```
(`P`는 settle 테스트의 Power 헬퍼와 같다.)

bash "$TEMP/ship.sh" "feat: the underground parking run" shared
