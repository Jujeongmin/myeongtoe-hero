# 출시 점검표 (8단계)

출시 전에 위에서부터 차례로 확인한다. `[x]`는 끝난 항목, `[ ]`는 남은 항목이다.

## 1. 빌드와 배포

- [x] `npm test`, `npm run typecheck`, `npm run server:test`가 모두 통과한다. 푸시할 때마다 `ship.sh`가 확인한다.
- [x] GitLab `develop` 푸시로 배포한다. 강제 푸시는 쓰지 않는다.
- [ ] Verse8 미리보기에서 실제 서버로 저장과 정산이 되는지 확인한다(`?local` 없이). 오프라인 복귀 보상, 이직, 주차장 결과 받기까지 본다.
- [ ] 휴대폰 실기기(안드로이드·iOS 하나씩)로 확인한다.
  - 세로 화면, 글자 겹침, 아래 탭, 웹툰 페이지를 본다.
  - 광고 재생 후 보상이 들어오는지 본다.

## 2. 스토어 등록 (Verse8)

- [ ] 게임 이름: 명퇴용사 박부장 / Early Retirement Hero Park
- [ ] 소개글: 한국어·영어 (대화에서 받은 초안을 그대로 붙여넣는다)
- [ ] 아이콘과 대표 이미지: 박부장 도트를 PixelLab으로 따로 만든다. 아직 없다.
- [ ] 스크린샷 4~5장: 전투, 보스 도전, 코스튬, 이직 제안서, 웹툰 한 페이지
- [ ] 지원 언어: 한국어, English, 日本語, 繁體中文, 简体中文

## 3. VX 상품 (대시보드)

- [x] 등록 시트 `docs/vx-dashboard.md`: 상품 13개, 이미지 13장(`art/vx/`), 가격과 설명이 다 채워져 있다.
- [ ] 대시보드에 13개를 등록한다. Product ID는 시트의 SKU와 글자 하나까지 같아야 한다.
- [ ] 테스트 결제로 보석이 지급되는지 확인한다(서버 `$onItemPurchased`). 프리미엄을 사면 버프 3종이 상시 켜지고 광고 없이 보상을 받는지도 본다.

## 4. 광고

- [ ] Verse8 광고 지면 ID를 등록한다: 보석·골드·상품권·주차권·2배속·버프 3종·방치 보상 한 번 더.
- [ ] 쿨다운 동안 다시 보기가 막히는지 확인한다(서버 기준 시각).

## 5. 밸런스

- [ ] `npm run sim`을 다시 돌린다. 버프 규칙, 프리미엄 상시 버프, 주차장 대기, 보스 교체가 바뀐 뒤라 확인이 필요하다.
  - 이직은 70층부터다. 무과금이 배속 광고만 보고 첫 접속 약 25분에 닿는다(`FIRST=30 npm run sim`).
  - D7·D30 도달 층이 이전 결과(약 130~145층, 180~200층)와 크게 다르지 않은지 본다.
- [ ] 주차장 깊이와 응시권 보상이 이직 응시권 대비 과하지 않은지 본다.

## 6. 콘텐츠

- [x] 웹툰: 프롤로그, 0.5화, 1~11화, 헤드헌터 편이 들어갔다.
- [x] 웹툰: 12~16화, 최종화, 쿠키, 옷장 특별편(코스튬 36종을 모두 모으면 열림)도 들어갔다.
- [x] 다국어: 문장 704개 모두 4개 언어로 번역했다(`npm run i18n`으로 빠진 문장을 확인한다).
- [x] 번체·간체 화면에서 글자가 넘치는 곳이 없다(360×740, 탭·메뉴·팝업 전부). 영어·일본어도 확인했다.
- [ ] 닉네임에 가나와 한자를 허용할지 정한다. 지금은 한글·영문·숫자만 받는다.

- [x] 저장 데이터는 공개되므로 개인정보를 넣지 않는다(`docs/VERSE8.md`).
- [x] 원작이 된 다른 게임 이름은 어떤 파일에도 쓰지 않는다.
- [x] 확률 공개: 동료 상자(함께하는 동료마다 같은 확률)와 보석 광고(5~20개, 개수마다 6.25%)의 확률을 게임 안에 보여준다(설계서 6.7).
- [ ] 이용약관: Verse8 기본 약관으로 충분한지 확인한다.
